# Icons Directory

This directory should contain application icons for the Tauri bundle.

Required icons:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)

You can generate these icons using the Tauri icon generation tool:
```bash
npm install --save-dev @tauri-apps/cli
npm run tauri icon path/to/source-icon.png
```
